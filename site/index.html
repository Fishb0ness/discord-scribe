A private note-taker for your Discord voice channel.

discord-scribe records each speaker separately, transcribes locally with whisper.cpp, and delivers a Markdown transcript and summary. You run your own Discord application on your own machine. There is no hosted service and nobody else can invite your bot.

Get it on GitHub Read the setup guide

From /grabar to Markdown

  1. Record

    The bot joins your voice channel, announces the recording in the text channel and writes one WAV file per speaker. The recording also stops by itself when the channel empties.

  2. Transcribe

    On /parar each track goes through whisper-cli on your machine. The turns are merged into one time-ordered transcript, and the WAV files are deleted once transcribed.

  3. Summarize

    Optionally, claude -p writes the summary. It is posted where /grabar was used, with transcript.md attached. If the summary fails, the transcript is still saved and posted.

recordings/2026-10-04_1705-general/
  transcript.md
  summary.md
transcript.md
[mm:ss] **Name**: text, time-ordered, consecutive turns of one speaker merged.
summary.md
Summary, decisions, and action items with owners.

Built to stay on your side.

  • Audio never leaves your machine

    Per-user audio goes to a temporary folder, is transcribed locally by whisper.cpp and is deleted once transcribed.

  • The summary is optional

    Only transcript text, not audio, goes to Anthropic, through the claude CLI and your own Claude login. With SUMMARY_ENABLED=false, claude is never run.

  • Only your servers

    ALLOWED_GUILD_IDS is required. The bot ignores interactions from anywhere else, DMs included, and leaves any other server it is added to.

  • Only people you allow

    Restrict /grabar with Discord's own command permissions. /parar only works for someone in the voice channel being recorded.

  • Nobody else can invite it

    Switch Public Bot off in the Developer Portal and only you can add the bot to a server.

  • Your token stays local

    It lives only in your .env, which git ignores. A pre-commit hook and a CI scan refuse to publish secrets.

Tell the people you record.

Recording voices has legal consequences (GDPR and similar laws). The bot announces the recording and renames itself for the whole session, but getting consent is your responsibility.

Runs on macOS, Linux and Windows.

  • macOS

    brew install whisper-cpp, then run it as a launchd LaunchAgent.

  • Linux

    Build whisper.cpp from source, then run it as a systemd user unit.

  • Windows

    Use the whisper.cpp release zip or build it, then run it as a Scheduled Task at logon.

Every system needs Node.js 22+ and git. The Claude Code CLI is only needed while summaries are on. The service installers start the bot at login and restart it on failure.

Good to know

  • The bot's chat messages and summary.md are in Spanish. Whisper defaults to Castilian Spanish; WHISPER_LANGUAGE and WHISPER_PROMPT change that.
  • Voice receive is unofficial in every Discord library and can break when Discord changes its voice protocol.
  • One recording per server at a time; transcription jobs run one after another.
  • CI covers tests and typechecking on all three systems, not a live Discord session.

Clone it, fill in .env, run it.

git clone https://github.com/Fishb0ness/discord-scribe
cd discord-scribe
npm install
npm run download-models   # large-v3 (about 3 GB) + Silero VAD
cp .env.example .env      # Windows: copy .env.example .env
npm start

You will also create your own Discord application and add its token and your server ID to .env. The README walks through every step.
